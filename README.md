# Zerodha Landing Page

A responsive Zerodha-inspired landing page built with HTML and CSS.

## Features

- Responsive navigation bar
- Centered navigation links
- Hero section with investment introduction
- Trust and confidence section
- Animated ecosystem image
- Feature cards
- Unbeatable pricing section
- Zerodha-style footer
- Hover effects for links and buttons
- Responsive layout for mobile devices

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS animations

## How to Run

1. Open `Zerodha.html` in Visual Studio Code.
2. Open the file in a web browser.
3. Ensure `ecosystem.png` is in the same folder as `Zerodha.html`.

## Project Structure

```text
zerodha/
├── Zerodha.html
├── ecosystem.png
└── README.md
```
